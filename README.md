# Offline Music Player 🎵

Offline Music Player is a fully functional music player that allows users to play audio files stored on their device without requiring an internet connection. It includes all essential playback utilities such as volume control, track navigation, and playback management, wrapped in a clean and user-friendly interface.

---

## 🚀 Features

- Play local audio files offline  
- Play & Pause controls  
- Next & Previous track navigation  
- Skip forward & backward  
- Volume control slider  
- Mute / Unmute audio  
- Track progress bar with seek functionality  
- Display current track information  
- Smooth and responsive UI  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- HTML Audio API
